# 📱 Phone Directory Manager

A professional **contact management system** built using **Streamlit, Pandas, and Excel storage**.  
This project demonstrates CRUD operations with a clean UI and modular Python architecture.

---

## 🚀 Features

- ➕ Add new contacts  
- 🔍 Search contacts by name or phone  
- 🗑️ Delete contacts with history tracking  
- 📜 View deleted contacts history  
- 🚫 Duplicate prevention (name & phone)  
- 📞 Phone number validation (7–15 digits)  
- 💻 Interactive Streamlit UI  

---

## 🛠️ Tech Stack

- Python 🐍  
- Streamlit ⚡  
- Pandas 📊  
- OpenPyXL 📁
